# 4_Presentation_Slides – Final Presentation

Slides for the 5-minute presentation (+5 minutes Q&A).

```text
index.html                 the deck: 14 animated slides in one HTML file
RB3302_Presentation.pptx   image-only copy for submission (one picture per slide)
assets/                    source images of the map (raw and cleaned)
```

`index.html` is self-contained. The fonts and map images are embedded, so it
works offline.

## Present

Open the deck in Firefox or Chrome and go full screen (`F11`):

```bash
firefox 4_Presentation_Slides/index.html
```

| Key | Action |
| --- | --- |
| `→` / `Space` / `Page Down` | Next slide |
| `←` / `Page Up` | Previous slide |
| `Home` / `End` | First / last slide |

- Add `#8` to the address to open slide 8.
- `E` turns edit mode on or off. `Ctrl+S` saves an edited copy.
- Add `?export` to the address to show each slide's final state with no
  animation. The `.pptx` images were made this way.

## The `.pptx`

Each slide in `RB3302_Presentation.pptx` is a 1920×1080 image of the HTML
slide. The text cannot be edited there and there are no animations. To change
a slide, edit `index.html`, then export the slides again.
